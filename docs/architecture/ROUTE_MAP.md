# Route map

> Contract for ADR 0001 §5 (IA before UI) and §6 (one page template, one header shell).
> A route that is in no navigation group, or a second path to something that already
> exists, is rejected here — not discovered later on a walk.

Generated from a read-only audit of `frontend/src/app` on 2026-09-06.

- **39 routes** in the dashboard tree.
- 19 render the shared page template; 20 do not.
- 15 still carry their own `<h1>`.
- 4 are orphans (in no nav group and linked from nowhere).

`tests/architecture/route-map.test.ts` enforces this map: every dashboard page must render
`ProPage`, redirect, or appear in a declared exception list **with a reason**; and every
route must be in the nav registry or carry a recorded way in. A new page that is neither
fails the build.
