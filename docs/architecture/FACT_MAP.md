# Fact map — one source per fact

> Contract for ADR 0001 §2. **Every fact the UI asserts to a customer has exactly one owning
> hook or selector.** Simple mode, Pro mode and the public site all read that one owner.
> Two components calling the same hook is correct; two components each deriving the same
> fact is a bug, because then two screens can disagree.

Generated from a read-only audit of `frontend/src` on 2026-09-06: six domain auditors
enumerated every customer-visible fact and every place it is independently derived.

- **65 facts** mapped across 10 domains.
- **56 are computed in more than one place** — the reason two screens disagree today.

## How to read this

`Computed in` lists every site that *independently derives* the fact. Where there is more
than one, the copies can drift apart, and the **Disagreement** column says how a customer
actually sees it. `Owner` is the single hook or selector that should produce it — an
existing one wherever a good one exists.
