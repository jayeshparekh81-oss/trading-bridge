4. OLD XBRL / TAG SANITY

  No NEW tag variant appeared — and that is not reassuring, because for the
  old era there is usually nothing to tag-match against. Findings:
    * Bank filings in format='Old' populate `re_basic_eps` in the detail
      API (HDFCBANK Mar-2015 11.40, SBIN Mar-2015 5.01). M2b's chain works.
    * Non-bank filings in format='Old' return detail_kind='none' — an empty
      payload with no EPS fields at all, so no tag chain can help.
    * NBFC (BAJFINANCE) returns an empty payload in EVERY year sampled
      2014-2021; in Round-1 those were recovered from the list row's XBRL
      URL, but that URL is a stub for all pre-~2019 filings.
    * The insurer could not be probed at all (no list rows), so the
      LI-taxonomy question from M2b is simply untestable in this era.

  Prices  2015-01-01 -> 2021-07-31: 1 daily request per symbol (Dhan serves a

==============================================================================
HONEST ASSESSMENT — can Round-2's window be built as specified?
==============================================================================

  No, not as specified. The price half is merely blocked on an expired Dhan
  token and would likely be fine after a refresh — that is an errand, not a
  finding. The EPS half is the real answer, and it is structural: NSE's
  filing list reaches back to 2005, but the filing CONTENT does not. For
  every non-bank symbol tested, quarterly EPS is simply absent before the
  filing format flips to 'New' (2016-2018 depending on the company), the
  detail API returns an empty payload, and the XBRL link that rescued 726
  NBFC filings in Round-1 is a stub for that era. Measured coverage over
  2014-Q3 -> 2021-Q2 is 100% for banks, ~50% for large non-financials, 11%
  for the NBFC, and 0% for the insurer. A C-gate needs a year-ago quarter
  for every scan day; at ~50% coverage it would fail closed on roughly half
  the universe for the first half of the window, which does not produce a
  weaker test of CANSLIM — it produces a different, bank-and-recent-IPO-
  weighted strategy wearing CANSLIM's name.

  THE SINGLE BIGGEST DATA RISK is not the missing EPS — it is that the gap
  is SECTOR-CORRELATED and would be invisible in aggregate counts. Banks
  survive it perfectly, NBFCs and insurers are wiped out, non-financials
  lose their pre-2018 half. Any Round-2 built on this would silently become
  a study of financials and 2017-18 listings, and its C-gate would be
  strongest exactly where Round-1 already showed the data is most awkward.
  If Round-2 proceeds, the honest options are to start the window at the
  format frontier (roughly 2018, which shortens it to ~3.5 years and loses
  the 2016-17 regime the round was meant to test), or to source EPS from a
  vendor with genuine old-era fundamentals rather than from NSE's archive.
