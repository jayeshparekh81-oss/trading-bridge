  portfolio, slots, tie-break, costs, slippage, exit-at-next-open, no
  rebalancing. The EMA220 leg and the -15% stop leg both stay ACTIVE.

  GEAR TRAIL, added on top; may only ever exit EARLIER than the base.
    peak           = highest CLOSE since entry
    max_profit_pct = peak / entry_fill - 1
    gear 1  max_profit < G2 trigger     -> no trail, base rules only
    gear 2  max_profit >= G2 trigger    -> exit if close <= peak*(1-G2 trail)
    gear 3  max_profit >= G3 trigger    -> exit if close <= peak*(1-G3 trail)
    Gear 3 supersedes gear 2; gears never step back down.
    Evaluated on the CLOSE, executed at the NEXT session's OPEN.

  RESCALE, declared before the run, original shape held exactly
    shape: G2 trail = 0.6 x G2 trigger; G3 trail = 0.089 x G3 trigger;
           G3 trigger = 1.8 x G2 trigger
    10x : G2 +25% / trail 15%   G3 +45% / trail 4%
    20x : G2 +50% / trail 30%   G3 +90% / trail 8%
    No third scale. No interpolation. No searching around a winner.

  DECLARED ATTRIBUTION: when a base leg and a gear fire on the same
  close, the exit is attributed to the BASE leg. A gear count therefore
  means 'the gear exited EARLIER than the base would have'.

  DECLARED LIMITS, written before the run
    1. The original gears are 15-minute intraday FUTURES parameters. At a
       133-session median hold they are meaningless unrescaled. The
       rescale above was declared, not chosen after seeing results.
    2. The original exits INTRABAR. This panel is daily-close only, so
       this is a WEAKENED version of the mechanism. A NEGATIVE RESULT
       HERE DOES NOT MEAN THE ORIGINAL DOES NOT WORK.

  DECLARED READING RULE: both scales moving the same direction versus
  control = evidence the mechanism is real. One scale winning while the
  other fails = NOISE, and must be reported as noise.

10. IS A PROFIT-CONDITIONAL TRAIL DIFFERENT FROM EXIT SPEED?
==============================================================================
  It is different, and it is WORSE. Every variant from Modules 3 and 4,
  sorted by median holding period:

     hold_med  cagr  exp_r  max_dd  trades   variant
         14.0  6.16   0.06  -24.15     788  M3 EMA20
         35.0 10.14   0.21  -25.28     411  M3 EMA50
         85.0 15.56   0.73  -28.82     179 M3 EMA150
         94.0 12.28   0.48  -24.37     198 SCALE-10x
        113.5 13.38   0.75  -26.42     146 SCALE-20x
        133.0 15.88   0.98  -25.36     117 M3 EMA220
        133.0 15.88   0.98  -25.36     117   CONTROL

  If the gear trail were unconditional exit speed under another name it
  would sit on the same hold-length curve. It does not. SCALE-10x holds
  LONGER than EMA150 (94 vs 85 sessions) and returns substantially LESS
  (12.28% vs 15.56% CAGR; 0.48R vs 0.73R). SCALE-20x is off the curve the
  same way.

  Mechanism: an unconditional moving average cuts indiscriminately, so it
  still lets some large winners run. A profit-conditional trail activates
  ONLY on trades that are winning, and tightens MOST on the ones winning
  biggest. In a book where five trades carry half the profit, a rule that
  targets the top of the winner distribution is strictly more damaging
  than one that cuts at random. Not the same effect renamed — the same
  effect plus an adverse-selection penalty.

    an EMA exit. It did not survive aggregation, but it is recorded as
    honest counter-evidence.
