HONEST ASSESSMENT — can this power the C-gate as-is?

  Yes, with four named caveats. 4,713 of 4,729 attainable quarter-slots
  (99.7%) carry a usable EPS, and 9,148/9,148 canonical filings
  carry an announcement timestamp — the two things the C-gate needs (a
  year-ago number and a point-in-time date to gate on). Only 16 quarters are
  genuine holes, each with a cause: 14 filings that contain no quarterly EPS
  fact at all (the company reported only half-year/full-year columns) and 2
  whose documents 404 on NSE's own archive.

  What is still weak, precisely:
  (1) COVERAGE IS NOT UNIFORM. 200 quarters are absent from NSE's own filing
      list, and MCX has NO old-regime data at all (24 quarters; only 2025+
      integrated filings exist). Five insurers depend entirely on the
      integrated regime for pre-2025 history. A C-gate over these names has
      fewer comparison points than its neighbours — M3 must fail closed on a
      missing quarter, never interpolate or carry forward.
  (2) CONSOLIDATED vs STANDALONE IS NOT INTERCHANGEABLE and the gap is large
      for specific names (ABB 6 cons vs 24 stand; AUBANK and BANDHANBNK have
      ZERO consolidated quarters). 13 symbols are standalone-only, 1 is
      consolidated-only. M3 must pick ONE series per symbol from the section-7
      table and hold it for the whole timeline; mixing them mid-history
      manufactures fake EPS jumps.
  (3) A LATE FILING IS A REAL POINT-IN-TIME TRAP. HDFCBANK's consolidated
      Mar-2021 result was not broadcast until 26-Apr-2022 (391 days), while
      its standalone landed on time. The dataset stores the true broadcast
      timestamp, so gating on announce_ts is correct and safe — but any code
      that joins EPS to price by PERIOD rather than by announcement date will
      look a year into the future for that symbol.
  (4) 316 values were recovered by INFERRING an XBRL context period from
      sibling contexts, because NSE's archive serves structurally invalid
      documents for older NBFC filings (facts reference contexts the file
      never defines). The inference only fires when every sibling agrees and
      the result still must pass the 60-130 day quarterly test, and each such
      value is tagged 'ok-context-inferred' in the cache — but it is an
      inference, not a stated fact, and is the first thing to re-verify if a
      financial-sector C-gate result looks surprising.

  A note on how much of this the M2a probe missed: its 12-symbol sample
  contained no NBFC and no insurer, so three sector-wide silent failures
  (bank/insurance XBRL tag names, the empty NBFC detail API, invalid NBFC
  XBRL) — 1,042 filings in total — were invisible to it and only surfaced
  because this module audited parse success by taxonomy instead of trusting
  row counts. Any future source probe should stratify by sector, not by
  interesting edge cases alone.
